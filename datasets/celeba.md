# CelebA Dataset

## Overview
CelebA (CelebFaces Attributes Dataset) is a large-scale face attributes dataset with more than **202,599 celebrity images**, each with **40 attribute annotations**.

## Relevance to Project
* Used to train our NLU parser to associate descriptive text adjectives with specific facial features.
* Used to initialize conditional generative model training.

## Key Attributes Used
* `Male`, `Young`, `Bald`, `Chubby`, `Double_Chin`, `Eyeglasses`, `Goatee`, `Mustache`, `Pale_Skin`, `Smiling`.
