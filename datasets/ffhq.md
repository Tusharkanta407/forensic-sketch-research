# FFHQ (Flickr-Faces-HQ) Dataset

## Overview
FFHQ consists of **70,000 high-quality PNG images** at $1024 \times 1024$ resolution. It contains a lot of variation in terms of age, ethnicity, and image background.

## Relevance to Project
* Standard dataset for training high-fidelity StyleGAN2/StyleGAN3 models.
* Provides the target photorealistic quality standard for Module 3.
