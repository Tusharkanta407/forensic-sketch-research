# Paper Implementations

This directory is designated for implementing the core algorithms from the research papers documented in the [papers/](../papers/) folder.

## 📝 Files to Implement

1. 🐍 **[`attention.py`](./attention.py)** — Implement the Multi-Head Attention layer from *Attention Is All You Need*.
2. 🐍 **[`arcface.py`](./arcface.py)** — Implement the Additive Angular Margin Loss layer from *ArcFace*.
3. 🐍 **[`facenet.py`](./facenet.py)** — Implement the Triplet Loss from *FaceNet*.
4. 🐍 **[`stylegan2.py`](./stylegan2.py)** — Implement Weight Modulation and Demodulation from *StyleGAN2*.

Please keep these implementations modular so they can be easily integrated into the main production repository later.
