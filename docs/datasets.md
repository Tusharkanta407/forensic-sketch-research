# Datasets for Forensic Sketch Generation

Below are the primary datasets targeted for this research:

| Dataset | Images | Attributes | Resolution | Use Case |
| :--- | :---: | :---: | :---: | :--- |
| **CelebA** | 202,599 | 40 facial attributes | $178 \times 218$ | Attribute parser and initial GAN conditioning |
| **FFHQ** | 70,000 | None (requires parsing) | $1024 \times 1024$ | High-fidelity face generator training |
| **CUHK Face Sketch (CUFS)** | 606 | Photos + Sketches | $200 \times 250$ | Style transfer / Forensic sketch mapping |
| **CUHK Face Sketch Evaluation (CUFSF)** | 944 | Photos + Sketches | Variable | Style evaluation |\n
