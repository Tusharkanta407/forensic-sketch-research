## Paper Summary Template

When reviewing a new paper, create `papers/concept/<paper-name>.md` using this format:

```markdown
# Paper Name: [Title]

## Authors
## Year
## Problem Statement
## Architecture
## Loss Function
## Input & Output
## Advantages
## Limitations
## How can we use it?
## Implementation Status
## Notes
```
